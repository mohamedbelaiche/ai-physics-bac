# عقل ثاني | فيزياء البكالوريا

منصة محادثة تعليمية عربية بالكامل، مصمّمة لتلاميذ البكالوريا الجزائرية (الشعب العلمية).
تعمل كـ«مدرّس ذكي» متخصص يشرح الدروس، ويحلّ التمارين خطوة بخطوة، ويراجع أهم أفكار المنهج،
اعتماداً على ملفات المعرفة الموجودة داخل المشروع (طبقة `raw/` و`wiki/`).

## المزايا

- واجهة دردشة عربية RTL بالكامل، مع شريط جانبي للمحادثات ونسخة مناسبة للموبايل.
- بثّ مباشر لإجابات النموذج مع زر إيقاف أثناء التوليد، وزر نسخ، وزر إعادة توليد.
- عرض المعادلات بـ KaTeX مع عزل اتجاهي، بحيث تبقى الرياضيات LTR داخل النص العربي RTL.
- استرجاع معرفي خفيف (RAG) من ملفات المشروع: يُحدَّد السياق المرتبط بالسؤال، ويُوسَم بـ [S#]، وتُعرض المصادر المستخدمة في الواجهة.
- تخزين محلي للمحادثات (وضع الزائر): إنشاء، إعادة تسمية، حذف، وبحث.
- موضوع مضيء وموضوع مظلم، وعناصر وصول موسومة بـ aria بالعربية، وتناسب الموبايل والحاسوب.

## الهيكل

```
app/                 الصفحات و نقطة API المباشرة /api/chat وصفحات خطأ عربية
components/          ChatApp · ChatWindow · MessageItem · ChatInput · Sidebar · MarkdownContent
lib/
  persona.ts         هوية المدرّس الذكي (system prompt)
  knowledge.ts       قصاصات المعرفة المرقّمة [S#] مستخلصة من raw/
  knowledge/
    retrieval.ts     محرك استرجاع خفيف (تطبيع عربي + ترجيح TF-IDF)
  ai/
    provider.ts      طبقة المزوّد (متوافق OpenAI — OpenCode Zen)
    chat.ts          تنقية التاريخ وبناء التوجيه وتشغيل البث
raw/ wiki/ templates/   طبقة المعرفة (مستثناة من Git افتراضياً، انظر .gitignore)
```

## التشغيل المحلي

```bash
npm install
# انسخ .env.example إلى .env.local وضع مفتاحك الحقيقي للـ API
npm run dev   # http://localhost:3000
```

## متغيّرات البيئة (على السيرفر فقط)

| المتغيّر | الدلالة | الافتراضي |
|---|---|---|
| `AI_API_KEY` | مفتاح OpenRouter | إلزامي |
| `AI_BASE_URL` | نقطة النهاية المتوافقة مع OpenAI | https://openrouter.ai/api/v1 |
| `AI_MODEL` | مُعرّف النموذج | z-ai/glm-5.3-flash |

للتحقق من قائمة الموديلات المتاحة: `curl https://openrouter.ai/api/v1/models`

## ما تبقى يدوياً والحدود الحالية

1. مفتاح API غير موجود في المستودع عن قصد؛ إعداد `.env.local` أو متغيّرات Vercel خطوة يدوية عليك.
2. طبقة Supabase (حسابات مستخدمين وتخزين سحابي) غير مفعّلة؛ وضع الزائر المحلي يعمل بدونها.
3. تحليل صور التمارين غير مفعّل؛ يجب أولاً التحقق من دعم النموذج للصور ثم توصيل الواجهة.
4. محدّد المعدل يعمل في ذاكرة مؤقتة محليّة، وهو تقريبي على بيئة Serverless؛ للحصول على حدّ ثابت استخدم خدمة قاعدة بيانات مثل Upstash.
5. ملفات `raw/` و`wiki/` الأصلية مستثناة من Git افتراضياً؛ المعرفة المنشورة موجودة داخل `lib/knowledge.ts`.
